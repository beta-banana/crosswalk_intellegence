# История изменений

Здесь отмечаются заметные изменения версий проекта.

## Следующая версия

- Текущий видеоэпизод заменён новой 162-секундной парой MP4+JSON из `video_and_json`; для браузера подготовлена H.264-копия с быстрым стартом.
- Настроены сбалансированные демонстрационные значения по умолчанию: максимальное ожидание ограничено 20 секундами для одиночного запроса и 15 секундами для группы, а раннее обслуживание разрешено при потоке до 24 авто/мин.
- Добавлены метрики доступности проезда для транспорта и честное описание модельного сравнения на готовой записи.
- Видеоэпизоды вынесены в реестр, поэтому дневную и вечернюю записи можно добавлять без загрузчика файлов и изменений frontend.
- Исправлены порт API для режима разработки и воспроизводимый запуск тестов из корня проекта.
- Убрана недостоверная привязка демонстрационной записи к Москве.
- Фазы, отображаемые поверх видеозаписи, явно обозначены как расчёты виртуального контроллера, а не измеренные состояния светофора.
- В интерфейсе удалено сравнение среднего ожидания как доказательство преимущества режима; добавлены доля обслуживания и число необслуженных модельных запросов.
- Добавлены материалы для защиты: трактовка метрик, ограничения эксперимента, аварийная архитектура и состав оборудования пилота.

## 1.1.0 — 27 сентября 2026

- Переведены на русский язык названия встроенных сценариев, режимы контроллера и основные подписи интерфейса.
- Улучшены формулировки статусов камеры, демонстрационных наблюдений и сравнения адаптивного управления с постоянным циклом.
- Сообщения о некорректных CV-данных теперь описаны на русском языке.
- Версия приложения, API и интерфейса синхронизирована на `1.1.0`.

## 1.0.0 — 27 сентября 2026

- Первая опубликованная версия прототипа с React-интерфейсом, FastAPI, сценариями симуляции и воспроизведением демонстрационного видео.
