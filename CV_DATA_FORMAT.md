# Минимальный формат данных CV

Для одного эпизода передайте **два файла** с одинаковым именем:

```text
crossing.mp4
crossing.json
```

`crossing.mp4` — видео H.264 в контейнере MP4. Зоны и найденные объекты уже нарисованы на кадрах. Время видео не должно быть ускорено или замедлено относительно JSON.

`crossing.json` — UTF-8 JSON с одним наблюдением на каждую секунду видео. Первый элемент массива относится к секунде `0`, второй — к секунде `1` и так далее. Отдельные временные метки, координаты зон, рамки объектов и ID треков передавать не нужно.

```json
{
  "seconds": [
    {"camera_ok": true, "vehicles": 2, "new_vehicles": 1, "waiting": 0, "new_pedestrians": 0, "on_road": 0},
    {"camera_ok": true, "vehicles": 1, "new_vehicles": 0, "waiting": 3, "new_pedestrians": 3, "on_road": 0},
    {"camera_ok": false, "vehicles": null, "new_vehicles": null, "waiting": null, "new_pedestrians": null, "on_road": null}
  ]
}
```

| Поле | Значение за эту секунду |
| --- | --- |
| `camera_ok` | `false`, если кадра нет или анализу нельзя доверять. |
| `vehicles` | Максимум одновременно видимых машин на подъезде к переходу. |
| `new_vehicles` | Число машин, впервые появившихся на подъезде. Каждую машину считать один раз за ролик. |
| `waiting` | Максимум одновременно ожидающих людей у перехода. |
| `new_pedestrians` | Число людей, впервые появившихся в зоне ожидания или на дороге. Каждого человека считать один раз за ролик. |
| `on_road` | Максимум одновременно находящихся на проезжей части людей, включая входящих на неё и переходящих. |

При `camera_ok: true` все пять счётчиков — целые числа от `0`. При `camera_ok: false` все пять счётчиков — `null`, **не нули**. Если объект уже виден на первой секунде, учтите его в `new_vehicles` или `new_pedestrians` для этой секунды. Длина массива `seconds` должна совпадать с длительностью видео с округлением вверх до целой секунды.

Этого достаточно: по `new_vehicles` мы считаем поток за предыдущие 30 секунд и транспортную статистику; по `vehicles` — свободную дорогу; по `waiting` — запрос и приоритет группы от 5 человек; по `new_pedestrians` — пешеходную статистику; по `on_road` — необходимость продлить пешеходную фазу; при `camera_ok: false` — резервный цикл. CV передаёт наблюдения, а рекомендуемые фазы рассчитывает наш backend.

Для текущей демонстрации приложение читает `result_crosswalk.json` как сценарий «Видео перехода». Видео для браузера отдаётся из `result_crosswalk_web.mp4`; это перекодированная копия исходного `result_crosswalk.mp4`, у которого отсутствовал индекс MP4. Сценарий содержит 194 посекундных наблюдения. Показания в JSON оценены по записи и дополнены демонстрационными значениями, поэтому не являются точным экспортом CV-модуля. Остальные встроенные сценарии доступны отдельно.
